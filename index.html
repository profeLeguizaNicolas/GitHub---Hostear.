Hostear en GitHub.

  1. Creá un nuevo repositorio en GitHub (Por ejemplo: mi-pagina).

    Ir a GitHub.

    O
    Click aquí para ir a GitHub

  2. Subí tus archivos con la siguiente estructura: 

        index.html
    style.css
    main.js

  3. Entrá a la pestaña Setting del repositorio.

  4. Bajá gasta la sección Pages (En el menú lateral).

  5. En Source, elegí la rama (por lo general main) y la carpeta /(root).

  6. Guardá los cambios Save.

    GitHub generará una URL como: 

        https://tu-usuario.github.io/mi-pagina/

    Tu archivo ingex.html será la página de inicio.
